# Проект автотестов для веб-приложения Stellar Burgers

Данный проект содержит набор автоматизированных UI-тестов для сервиса **Stellar Burgers**. Тесты написаны на языке **Python** с использованием фреймворка **Pytest** и инструмента автоматизации **Selenium WebDriver**.

Тесты сгруппированы в логические классы, конфигурация и тестовые данные вынесены в фикстуры, интегрировано сквозное логирование.

---

## 🛠️ Технологический стек

*   **Язык программирования:** Python 3.14+
*   **Фреймворк для тестирования:** Pytest 9.0+
*   **Инструмент автоматизации:** Selenium WebDriver 4+
*   **Генерация тестовых данных:** Faker
*   **Библиотеки отчетов и логирования:** Встроенный модуль `logging`

---

### ⚙️ Реализованные фикстуры (`conftest.py`)
1.  `setup_logging` (область `session`, `autouse=True`) — автоматически настраивает формат логов, выводит их в консоль Bash и параллельно записывает в файл `automation.log`.
2.  `driver` — инициализирует браузер Chrome, а после окончания теста (через `yield`) изолирует сессию: зачищает `cookies`, `LocalStorage`, `SessionStorage` и корректно закрывает процесс браузера.
3.  `user_data` — генерирует случайные валидные данные (имя, почту, пароль) через `Faker`.
4.  `registered_user` — регистрирует сгенерированного пользователя на сайте «за кадром», возвращая готовые креды для тестов авторизации.
5.  `authorized_user` — берет зарегистрированного пользователя и выполняет полноценный вход на сайт, подготавливая браузер для тестов навигации и выхода.

## 🧪 Покрытые тест-кейсы

Все тесты распределены по **четырем ключевым классам**:

1.  **`TestRegistrationMainPage` (Регистрация):**
    *   Успешная регистрация нового пользователя с автоматической проверкой перенаправления на страницу входа.
    *   Негативный сценарий регистрации с вводом некорректного (короткого, менее 6 символов) пароля и валидацией сообщения об ошибке.
2.  **`TestAuthorization` (Авторизация):**
    *   Вход по кнопке «Войти в аккаунт» на главной странице.
    *   Вход через кнопку «Личный кабинет» в шапке сайта.
    *   Вход по ссылке внутри формы регистрации.
    *   Вход по ссылке внутри формы восстановления пароля.
3.  **`TestNavigation` (Переходы и Конструктор):**
    *   Переход авторизованного пользователя в раздел «Личный кабинет» с проверкой корректности отображения имени.
    *   Переход из личного кабинета в конструктор по клику на кнопку «Конструктор».
    *   Переход из личного кабинета на главную страницу по клику на логотип Stellar Burgers.
    *   Переключение и фокус вкладок внутри самого конструктора: «Булки», «Соусы», «Начинки».
4.  **`TestLogout` (Выход из аккаунта):**
    *   Выход из профиля по кнопке «Выйти» в личном кабинете с проверкой возврата на форму авторизации.

## 🚀 Инструкция по запуску тестов

### 1. Подготовка окружения
Убедитесь, что вы находитесь в корневой папке проекта (`cd C:\Sprint5`) и у вас установлены все зависимости: Selenium, Pytest, Faker.

### 2. Запуск всего тестового набора
Для запуска всех 13 тестов с отображением логов в реальном времени в bash-консоли используйте команду:
```bash
pytest -s -o log_cli=true
```

### 3. Запуск конкретного класса тестов
Если вам нужно запустить только одну группу тестов (например, навигацию), выполните команду с фильтрацией по имени класса:
```bash
pytest -s -o log_cli=true -k "TestNavigation"
```

### 4. Просмотр файла логов
После прохождения тестов в корне проекта автоматически создается файл **`automation.log`**. Логирование ведется на русском языке, записывая каждый важный шаг теста:
```text
2026-06-22 15:10:02 [INFO] Авторизуем пользователя: fake_user@yandex.ru
2026-06-22 15:10:05 [INFO] Выполняем переход в личный кабинет по клику на «Личный кабинет»
2026-06-22 15:10:06 [INFO] Выполнен переход в личный кабинет по клику на «Личный кабинет».
```
